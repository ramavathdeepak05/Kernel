## What is this folder?

Everything related to the QUAICU–Woxsen collaboration lives here.
QUAICU's core platform code is in `ALIS/` and `web/` at the repository root
and is not within Woxsen's development scope.

## Woxsen's Development Scope at a Glance

**Phase 2** — Provide domain rules, anonymised test data, and UAT for all
edge case resolvers. QUAICU writes the code.

**Phase 3** — Co-develop E14 Regulatory (NAAC/NIRF/UGC content and mapping)
and E19 Quota Seat Matrix (category configuration). QUAICU builds the engines.

**Phase 4** — Build and own: Faculty dashboard, Student dashboard, HOD dashboard,
Admissions public portal (student-facing), NAAC/Regulatory dashboard,
Parent/Guardian portal UI.

**Phase 5** — Co-develop E15 PhD Research (domain logic, DC workflows, ethics),
E17 Re-admission, E18 Convocation, E20 OBE/CO-PO, and Telugu localisation.

Full deliverable breakdown with QUAICU/Woxsen task split: see `legal/SOW.md`.
