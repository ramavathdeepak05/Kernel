# How-To Guides

Task-oriented guides for specific operations. These assume you have the kernel running — see the [Quickstart →](../quickstart.md) if you haven't yet.

| Guide | Use when |
|-------|----------|
| [Write a Policy](write-a-policy.md) | You need to define a new governance rule using CEL |
| [Configure HITL](configure-hitl.md) | You need human approval gates before execution |
| [Set Up Observability](setup-observability.md) | You want OpenTelemetry traces, Prometheus metrics, or logs |
| [Deploy Sovereign](deploy-sovereign.md) | You need on-premise or air-gapped deployment |
| [Deploy Dedicated (VPC)](deploy-dedicated.md) | You need customer-VPC deployment on GCP or AWS |
| [Build an Adapter](build-an-adapter.md) | You need to add a new model provider or storage backend |
| [Verify a Ledger Proof](verify-ledger-proof.md) | You want to verify an RFC-6962 inclusion proof offline |
